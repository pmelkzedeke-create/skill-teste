# skill-teste

Repositório de teste da skill **short-form-storyteller-3d**.

- `short-form-storyteller-3d/` — a skill instalada (extraída de `short-form-storyteller-3d-ready.zip`).
- `short-form-storyteller-3d-ready.zip` — pacote original, mantido como fonte.
- `INSTALL.md` — o que a skill faz, como está o ambiente deste sandbox e como renderizar numa máquina completa.

## Uso

Envie apenas o tema, por exemplo:

> Faça um vídeo sobre: por que o céu fica vermelho no pôr do sol

A skill produz roteiro, animação 3D low-poly, narração, trilha, legendas e MP4 vertical 1080×1920 em
`output/<tema>/`. Padrões: pt-BR, 45 s, 30 fps, TTS gratuito, nada pago e nada publicado.
